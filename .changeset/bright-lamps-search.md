Rebuild search: More features and much better performance. You can now set 'match case', 'whole word' and 'regex' for the search string, choose where to search, what to include and how to order the results. The new layout is designed to work whether the extension is docked below, to the side or undocked on a second monitor. Settings were added allowing you to choose which search settings you want the extension to remember.
